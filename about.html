About this site

A local guide to events in the Chamonix valley — what's on tonight, this weekend, and next week. Built from public sources, curated by a single operator.

01

What this is

This is a focused, opinionated guide to events in Chamonix, Les Houches, Argentière, and nearby communes. The site is built from public data sources, refreshed automatically several times a day, and curated by a single operator (Jamie) — not by AI or by a content team.

The goal is to be useful for one decision: "what should I do tonight?" The site shows cinema, concerts, exhibitions, family events, markets, sport, and theatre. It does not show generic tourism content, hotel offers, or restaurant menus.

03

Confidence & review

Every event gets a confidence score from trust × parse_quality × completeness. Events below the publish threshold (default 0.4) are routed to a review queue instead of being shown on the site. The threshold is per-source and configurable in sources.yaml.

How confidence works

0.0 – 0.4
Queued for review — sparse data, parser issues, or low source trust. Operator decides whether to publish.
0.4 – 0.6
Published — partial data. Standard publish threshold.
0.6 – 1.0
Published — full data, well-parsed. Aspirational target as data quality improves.

The review queue lets the operator approve or reject queued items. Approved items are remembered; rejected items are kept for the audit trail. The queue is currently open.

04

Methodology

The pipeline runs every 6 hours on the host (cron-driven). Each run:

  • Scrapes chamonix.net (events listing)
  • Scrapes chamonix.com (events listing)
  • Parses the cinema PDF and enriches posters via TMDB + AlloCine
  • De-duplicates events across sources (same title + same date → keep the highest-confidence one)
  • Routes below-threshold events to the review queue
  • Renders the static HTML page you see

The system is built to be predictable: the same input produces the same output. No AI-driven scraping, no live translation, no per-user ranking.

06

What this site is not

For transparency, here is what this site does not do, so expectations stay realistic:

  • It is not a hotel or restaurant guide.
  • It does not show real-time event capacity or ticket availability.
  • It does not auto-translate every event — some entries appear in the source language.
  • It does not run on a managed cloud — it runs on a single VPS, supervised.
  • It does not track you, log your visits, or serve ads.
