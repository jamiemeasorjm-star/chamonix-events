# Product Brief — Chamonix Events Calendar

## Vision

A unified, rolling calendar of everything happening in the Chamonix valley.

## Audience

- **Visitors:** Planning trips of a week or more, want to know what's on
- **Locals:** Want a single source of truth for events, especially fragmented sources (nightlife, pop-ups)

## Core Value Proposition

- One place to see all events
- Date-range picker + filters (category, commune, venue)
- Nightlife included (usually very fragmented)
- Mobile-first, fast, no ads

## Non-goals (v1)

- Not an itinerary builder
- Not a replacement for official venue sites
- Not a social platform
- Not monetised in v1

## Success Criteria (v1)

- Events from 3+ sources reliably ingested
- Calendar view works on mobile and desktop
- Filters are usable and responsive
- Review queue catches obviously wrong events before publish
- Under 2s page load on 4G
